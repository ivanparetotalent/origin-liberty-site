This file is the scaffold reference for new blog posts. It is marked `draft: true` and excluded from the production build.

## How to add a new post

1. Copy this file to `src/content/blog/<slug>.mdx`
2. Update the frontmatter (`title`, `description`, `publishDate`, `tags`, `draft: false`)
3. Write your post in MDX

## What MDX gives you

You can write **bold**, _italics_, links, lists, code blocks &mdash; and import Astro components inline if you need to.
